# Dinosaur World SBA

Proyecto para desarrollar un mundo de dinosaurios para Super Bear Adventure.

## Estado actual

Este repositorio es el punto de partida del proyecto. La importación de un paquete de prueba en SBAModLoader confirmó que el gestor reconoce el paquete, pero todavía no confirma que exista un mundo jugable integrado.

## Objetivo

- Diseñar el escenario Dinosaur World.
- Preparar modelos y recursos 3D originales o autorizados.
- Documentar el formato de integración compatible con la versión del juego y SBAModLoader.

## Pendiente

No se incluye una APK modificada ni un mod jugable compilado. Para lograrlo hacen falta los formatos de recursos y la API/versión exacta que acepte el cargador.
