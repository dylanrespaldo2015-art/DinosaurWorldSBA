# Dinosaur World SBA

Proyecto para desarrollar un mundo de dinosaurios para Super Bear Adventure.

## Prototipo jugable en navegador

Abre [index.html](./index.html) desde GitHub o activa GitHub Pages para publicarlo como sitio web. En el prototipo puedes caminar por una isla, saltar y recoger cinco huellas.

- Móvil: usa las flechas táctiles y el botón ¡SALTA!.
- PC: usa WASD o las flechas y la barra espaciadora.

## Estado actual

Este es un prototipo independiente para probar la idea del mundo. **No es todavía un mod integrado ni un nivel cargable dentro de Super Bear Adventure.** La importación de un paquete de prueba en SBAModLoader solo confirmó que el gestor reconoce el paquete; no que el mundo esté integrado.

## Próximos pasos para el mod

- Identificar el formato de contenido y la API que admite la versión instalada de SBAModLoader.
- Preparar modelos y recursos 3D originales o autorizados.
- Adaptar el escenario al formato compatible y probarlo en el juego.

No se incluye una APK modificada ni un mod jugable compilado.
